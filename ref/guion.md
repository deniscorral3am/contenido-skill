# Estructura de un guion de reel (30–75 s; por API Instagram acepta hasta 90 s)

```
GANCHO (0–3 s)        consecuencia o tensión · 3 opciones con mecanismos distintos
CONTEXTO (3–8 s)      por qué te debería importar: el dolor del avatar con sus palabras
VALOR (8–50 s)        3 pasos / 3 ideas, una frase por idea, un ejemplo concreto del nicho en cada una
PRUEBA (opcional)     solo real: un caso, una captura, una cifra de las métricas
GIRO / RESUMEN        la frase que se queda (la que comparten)
CTA (últimos 3–5 s)   «Si quieres [recurso], comenta PALABRA» → el setter hace el resto
```

## Embudo (lo marca el estratega en cada pieza)
- **TOFU** (alcance): tema amplio del nicho, gancho fuerte, CTA suave (seguir / comentar).
- **MOFU** (autoridad): tu método, tus pasos, tu forma de ver el nicho. CTA con lead magnet.
- **BOFU** (venta): casos reales, objeciones de las llamadas respondidas, detrás de la oferta. CTA a la palabra que
  lleva al setter y a la llamada.

## Psicología (de `cerebro/audiencia.md` y `cerebro/llamadas-de-venta.md`)
- Habla al **nivel de consciencia** del avatar: si no sabe que tiene el problema, enséñale el síntoma; si compara
  soluciones, enséñale por qué la tuya es distinta.
- Cada guion rompe **una** creencia que le frena o responde **una** objeción literal.
- El texto en pantalla resume, no repite.

## Formato de entrega (guiones/AAAA-MM-DD-<slug>.md)
```
# <título>  ·  C004 · TOFU · a cámara · 45 s
Para: <avatar en una línea> · Rompe: <creencia/objeción> · Sale de: <idea I012 / métrica / llamada>

## Ganchos
1. (dicho) … · (pantalla) … · mecanismo
2. …
3. …

## Guion (palabra por palabra, como hablas tú)
…

## Texto en pantalla
…

## Caption
… (los primeros 125 caracteres se ven antes de «más») · CTA con la palabra

## Variantes para trial reels
- Gancho B: … · Gancho C: …
```
